FPS LAB — пакет сайта

Файлы:
- index.html: главная страница и калькулятор
- style.css: оформление
- script.js: логика калькулятора
- privacy.html: черновик политики конфиденциальности
- contact.html: страница контактов

Публикация на GitHub Pages:
1. Распакуйте архив на компьютере.
2. Войдите на https://github.com/ и создайте Public repository с именем fps-lab.
3. Нажмите Add file → Upload files и загрузите ВСЕ пять файлов в корень репозитория.
4. Нажмите Commit changes.
5. Откройте Settings → Pages.
6. В Build and deployment выберите Deploy from a branch, branch main, folder /(root), нажмите Save.
7. Подождите несколько минут и откройте ссылку, которую покажет GitHub Pages.
